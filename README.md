# MeshWeaver

MeshWeaver is a distributed system designed to share workloads across multiple nodes. It uses node communication, load monitoring, and task routing to improve resource utilization and system reliability.

## Features
- System resource monitoring
- Peer discovery and communication
- Gossip-based load sharing
- Intelligent task routing
- Load balancing and fault handling

##Technologies used
- Python
- JSON
- Git and GitHub

## Project Structure
The project is organized into modules for load collection, gossip communication, peer discovery, task routing, and testing.

## Installation

Clone the repository:

```bash
git clone <repository-url>
```

Install required dependencies:

```bash
pip install -r requirements.txt
```

## Execution
Refer to the individual module instructions to run the project.
