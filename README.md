# MeshWeaver

## About
MeshWeaver is a distributed task queue system built using Python. It allows multiple nodes to communicate, discover peers, share workloads and execute tasks without a central server.

## Features
- Peer discovery using Kademlia DHT.
- Node communication using networking protocols.
- Load sharing using Gossip protocol.
- Distributed task execution.
- Fault tolerance and task re-routing.

## Technologies Used
- Python
- Asyncio
- Kademlia DHT
- UDP / TCP
- Git & GitHub
